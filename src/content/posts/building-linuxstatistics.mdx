Nobody knows how many people use each Linux distro. Windows and macOS check in with Microsoft and Apple; Linux doesn't check in with anyone, and most distros never phone home. Every "most popular distro" chart is really measuring attention.

[LinuxStatistics](https://linuxstatistics.com) is my attempt at a leaderboard that says so up front: "interest, not installs," right in the headline.

## It started as a solar system

The first version was 3D. Each distro was a planet, sized by popularity, orbiting its family. It looked great in a screen recording and was useless for picking a distro.

I parked it and shipped a table. The table was the thing I kept opening anyway.

## Four mockups, one day

I didn't start from a moodboard. I built four styles against real data and lived with them for a day. The winner mixed a bold headline and podium with a dense, monospace data table, plus a neon green I checked against major brand colors so it wouldn't read as someone else's.

## Numbers you can check

The rank blends four signals: Wikipedia views, DistroWatch rank, GitHub stars and views on the site. Each signal has its own blind spots, and mixing them keeps any single source from setting the order. The weights are public, and every change goes in a changelog.

The other pages answer real questions. Which distros send usage data by default? I checked 51 against their own docs, and 31 send nothing. When does my release stop getting updates? Mint or Fedora if I'm leaving Windows?

The data is open: CC BY, a keyless API, CSV downloads. The code is AGPL.

## The tooling

Same deal as this site: I make the calls, agents do the typing. The lesson at this size was that agents write code that passes the check you gave them. They're bad at noticing when the check itself is wrong, so most of the project's guardrails exist because a check once lied to me.

## Ope.

It's live in a soft launch, and the data gets better every day. If you spot a distro with wrong data, there's a suggest form on the site.
