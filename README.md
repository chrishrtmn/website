# chrishrtmn.com

- [Vercel](https://vercel.com)
- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com)
- Framer Motion

## Running Locally

This application requires Node.js v14.18.0+.

```bash
git clone https://github.com/chrishrtmn/website.git
cd website
pnpm install
pnpm dev
```
